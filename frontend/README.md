# Frontend - Adresse Opslag

React SPA til adresse lookup med autocomplete funktionalitet.

## Teknologier

- React 19
- TypeScript
- Vite
- Tailwind CSS

## Opsætning

1. Installer dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

Applikationen vil være tilgængelig på `http://localhost:5173`

## Build

For at bygge til produktion:
```bash
npm run build
```

## Features

- Autocomplete adresse søgning
- Henter data fra Dataforsyningen API via backend
- Responsivt design med Tailwind CSS
- TypeScript for type safety
